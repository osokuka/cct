Import Format

This import accepts CSV files in the exact format provided by the client:

  • BLDG Location - Building location description

  • Qty of rooms - Quantity of rooms
  • Actual Sqm (m2) - Effective area for SLA

  • Max Frequency Per Month - Monthly cleaning cap
  • Total m² Week - Weekly SLA baseline
  • EoM Invoicing max. Sqm (m2) - Monthly invoicing cap
  • # Weeks of service - Service duration
  • Start Date - Service start (DD-MMM-YY)
  • End Date - Service end (DD-MMM-YY)
